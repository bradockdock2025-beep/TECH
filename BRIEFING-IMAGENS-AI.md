# Briefing Visual — Imagens AI por Secção

Cada descrição abaixo define exactamente o que deve aparecer na imagem gerada.  
O objectivo é mostrar a **homepage do template** como se fosse uma screenshot real do browser.

---

## SECÇÃO SERVICES

---

### 01 — Website Institucional

**O que o visitante do site vai ver:**  
Um template de website institucional/portfolio — o tipo de site que uma empresa, marca ou profissional usa para apresentar o negócio online.

**Estrutura visível na imagem (de cima para baixo):**

```
┌─────────────────────────────────────────────────┐
│  NAVBAR                                         │
│  Logo à esquerda · Links ao centro · CTA direita│
├─────────────────────────────────────────────────┤
│  HERO (secção principal)                        │
│  Headline grande e bold à esquerda              │
│  Subtítulo em baixo                             │
│  Dois botões: "Contactar" + "Ver trabalho"      │
│  Imagem ou foto do produto/serviço à direita    │
├─────────────────────────────────────────────────┤
│  SECÇÃO DE SERVIÇOS (3 cards lado a lado)       │
│  Ícone + Título + Descrição curta               │
└─────────────────────────────────────────────────┘
```

**Estilo visual:**
- Fundo: branco ou cinzento muito claro
- Tipografia: serif elegante ou sans-serif bold moderna
- Paleta: preto/branco/azul accent — look premium e sério
- Espaço em branco generoso (não apinhado)
- Aspecto de empresa profissional, não de startup tech

**Detalhes de conteúdo visíveis:**
- Logo com nome de empresa fictícia (ex: "NOVA Studio")
- Headline: algo como "Construímos espaços que inspiram" ou "A estratégia que o seu negócio precisa"
- Foto: imagem de produto, pessoa em escritório, ou render 3D abstracto
- 3 cards de serviços com ícones lineares simples

**Formato da imagem:**
- Screenshot de browser desktop (com a barra do browser visível no topo)
- Proporção 16:9 ou 3:2
- Nitidez alta, iluminação limpa

### 02 — E-commerce

**O que o visitante do site vai ver:**  
A homepage de uma loja online — o tipo de site que uma marca de moda, lifestyle, beleza ou produto físico usa para vender online.

**Estrutura visível na imagem (de cima para baixo):**

```
┌─────────────────────────────────────────────────┐
│  NAVBAR                                         │
│  Logo · Categorias · Pesquisa · Carrinho (nº)   │
├─────────────────────────────────────────────────┤
│  HERO BANNER (full width)                       │
│  Foto de produto grande + headline de oferta    │
│  Botão "Comprar agora" ou "Ver colecção"        │
├─────────────────────────────────────────────────┤
│  NOVIDADES / PRODUTOS EM DESTAQUE               │
│  Grid 4 produtos: foto + nome + preço + botão   │
├─────────────────────────────────────────────────┤
│  BANNER SECUNDÁRIO                              │
│  Promoção ou nova categoria                     │
└─────────────────────────────────────────────────┘
```

**Estilo visual:**
- Fundo: escuro (preto/cinzento muito escuro) — look premium de marca de moda
- Tipografia: serif clássica para o nome dos produtos, sans bold para preços
- Paleta: preto + branco + gold ou nude — elegância de luxury brand
- Fotos de produto em fundo neutro, proporção quadrada ou portrait
- Carrinho com número visível no canto superior direito

**Detalhes de conteúdo visíveis:**
- Logo de marca fictícia elegante (ex: "MAISON K" ou "LUNA")
- Categorias no menu: "Mulher · Homem · Novidades · Sale"
- Hero: modelo com roupa, headline "Nova Colecção Verão 2025"
- Grid de produtos: 4 peças de roupa com preços (ex: €89, €145, €67, €220)
- Badge "Novo" ou "−20%" em alguns produtos
- Ícones de pagamento no rodapé: Visa, Mastercard, MB Way, PayPal

**Formato da imagem:**
- Screenshot de browser desktop
- Proporção 16:9
- Alta qualidade, cores vibrantes dos produtos

### 03 — Aplicativo / Dashboard

**O que o visitante do site vai ver:**  
Uma composição com dois ecrãs lado a lado — o dashboard desktop à esquerda (maior) e o ecrã mobile à direita (menor). Mostra um software de gestão interno.

**Estrutura do DASHBOARD DESKTOP (à esquerda, maior):**

```
┌──────────────────────────────────────────────────────┐
│  SIDEBAR (esquerda, escura)    │  ÁREA PRINCIPAL      │
│  Logo da app                   │                      │
│  • Dashboard  ← activo         │  ┌──┐ ┌──┐ ┌──┐    │
│  • Projetos                    │  │KPI│ │KPI│ │KPI│   │
│  • Equipa                      │  └──┘ └──┘ └──┘    │
│  • Relatórios                  │                      │
│  • Definições                  │  GRÁFICO DE BARRAS   │
│                                │  (crescimento mensal)│
│  Avatar do utilizador em baixo │                      │
│                                │  TABELA DE TAREFAS   │
│                                │  com status colored  │
└──────────────────────────────────────────────────────┘
```

**Estrutura do ecrã MOBILE (à direita, menor):**
```
┌──────────────┐
│  HEADER APP  │
│  "Olá, João" │
├──────────────┤
│  MÉTRICA     │
│  grande e    │
│  destacada   │
├──────────────┤
│  Lista de    │
│  tarefas     │
│  recentes    │
├──────────────┤
│  BOTTOM NAV  │
│  🏠 📊 ✅ 👤 │
└──────────────┘
```

**Estilo visual:**
- Fundo geral: escuro (dark UI — #0f0f18 ou equivalente)
- Sidebar: cinzento muito escuro com item activo em azul
- Cards de KPI: fundo ligeiramente mais claro, número grande em branco, label pequena em cinzento
- Gráfico: barras em gradiente azul
- Tabela: linhas alternadas, badges de status (verde "Concluído", amarelo "Em progresso", cinzento "Pendente")
- Mobile: cantos arredondados, sombra, screen dentro de frame de smartphone

**Detalhes de conteúdo visíveis nos KPIs:**
- "2.4k Utilizadores activos"
- "98% Uptime"
- "€47.2k Receita este mês"

**Formato da imagem:**
- Composição (não screenshot de browser) — dois dispositivos flutuando
- Fundo muito escuro ou transparente
- Sombras suaves sob os dispositivos
- Proporção 16:9 ou 4:3

## Notas de Produção

**Resolução:** Gerar a 2x (pelo menos 1600px de largura)  
**Formato:** JPG ou WebP, qualidade 90%  
**Tamanho final alvo:** < 300KB cada (optimizar após geração)  
**Idioma do conteúdo nas imagens:** Português ou inglês — ambos funcionam  
**Texto nas imagens:** Pode ser ligeiramente ilegível/placeholder, o que importa é a estrutura e o estilo visual
